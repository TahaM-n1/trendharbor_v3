# trendharbor_v3

TrendHarbor is a cross-platform mobile and web application built using Flutter and Firebase (Firestore + Realtime Database). It connects influencers, businesses, and consumers through an innovative ecosystem that blends social media engagement, e-commerce, and escrow-secured transactions.

🔑 Core Features:
User Authentication & Profile Management
Supports registration for Consumers, Influencers, and Organizations, with password recovery, editable profiles, and role-based access control.

Influencer Collaboration & Campaigns
Influencers can set collaboration preferences. Brands/organizations can discover and initiate paid promotional partnerships directly within the app.

Social Media Integration & Content Promotion
Influencers can publish campaign content, share posts, and engage users through in-app social feeds, likes, and promotions. Users can explore products through influencer-endorsed media.

Escrow-Based Collaboration
Secure transactions with escrow. Payments are held until confirmation by all involved parties to ensure trust and prevent fraud.

Real-Time Updates & Notifications
Powered by Firebase Realtime Database, users get instant updates about orders, promotions, and campaign activity. Notifications can be enabled/disabled based on preference.

User Feedback System
Two types of feedback: one for event/campaign effectiveness and one for overall user experience using structured survey questions.

Smart Shopping Experience
A curated store powered by influencer promotions, with intuitive navigation from product discovery to secure checkout.

Maximum Efficiency
Developed using modern, scalable technologies with a focus on clean UI, usability, and performance across Android, iOS, and web.

🎯 Project Objective:
To create an engaging social-commerce platform where influencers promote products, businesses gain exposure, and consumers enjoy a trusted shopping experience—all powered by real-time interactions and secure payments.
